# Project brief

- **Goal**: HexaWave is an AI software factory with tenant-private workspaces, prompt-driven app generation, code editing, build/run/preview, and company software approvals.
- **Non-goals**: Live broker execution, offensive intrusion tooling, exploit kits, unauthorised access.
- **Success criteria**: The IDE supports prompt-led fast/full project generation, editing, search, build, run, preview, and downloadable files. Project code is scoped by the authenticated company or individual workspace. Fast mode reduces a planning step but does not guarantee a one-minute completion time.
